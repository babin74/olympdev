Сделано: грамматика тегов, `parse_solution_tag` / `match_solution_tag`,
верификация (`ProblemVerificationPipeline`, `p.verify()`, `olympdev verify`).
Описание тегов — в README.

- [x] Снять жёсткий список значений в `ProblemSolution._check_tag`
      (грамматика: `main` / `OK` / `incor` / `ignore` / `Q1+…+Qn`, не произвольные строки)
- [x] Согласовать `get_permissible_verdicts` / `get_expected_verdicts`
- [x] Описать допустимые теги в README

Уникальность тегов проверяется при загрузке (`ProblemConfiguration._check_solution_tags`):
`main` ровно один, остальные теги не повторяются.

Predictable errors: `WA`, `TL`, `ML`, `RE`, `PT`.

- `Q1+…+Qn`: перечисленные вердикты и `OK` разрешены; каждый токен без `?`
  обязан встретиться (`TL+WA` — и `TL`, и `WA`).
- `incor` — хотя бы один predictable error.
- `ignore` — не запускать.
